## त्वरित शुरुआत

### आपको क्या चाहिए

- **macOS** 10.15 या बाद का संस्करण
- **4GB RAM** न्यूनतम (8GB अनुशंसित)
- **ऑडियो फ़ाइल** MP3, WAV, M4A, FLAC, OGG, या WEBM प्रारूप में

### पहला लॉन्च

1. LocalMind डाउनलोड करें
2. एप्लिकेशन फ़ोल्डर में ले जाएं
3. खोलने के लिए डबल-क्लिक करें
4. यदि अनुरोध किया जाए तो अनुमतियां दें

बस इतना ही। कोई खाता नहीं। कोई सदस्यता नहीं। इंटरनेट की आवश्यकता नहीं।

## आपका पहला ट्रांसक्रिप्शन

### चरण 1: अपना ऑडियो जोड़ें

अपनी ऑडियो फ़ाइल को विंडो में ड्रैग और ड्रॉप करें।

**समर्थित प्रारूप:**
MP3 · WAV · M4A · FLAC · OGG · WEBM

**फ़ाइल आकार:**
प्रति फ़ाइल 2GB तक

### चरण 2: प्रोसेसिंग कॉन्फ़िगर करें

अपनी प्राथमिकताएं चुनें:

**प्रोसेसिंग मोड:**
- **ऑफ़लाइन** - आपके डिवाइस पर स्थानीय रूप से प्रोसेस करता है
- **ऑनलाइन** - क्लाउड AI का उपयोग करता है (API कुंजियों की आवश्यकता है)

**भाषा:**
स्वतः-पहचान या 50+ भाषाओं में से चुनें

**मॉडल:**
Large V3 (सर्वोत्तम गुणवत्ता) - पहले उपयोग के लिए अनुशंसित

**ऑडियो प्रीप्रोसेसिंग:**
स्पष्ट परिणामों के लिए शोर कमी सक्षम करें

### चरण 3: प्रोसेस करें

**प्रोसेस करें** पर क्लिक करें और पाइपलाइन देखें:

1. **ट्रांसक्रिप्शन** - भाषण को टेक्स्ट में बदलना
2. **चैनल मर्ज करें** - ऑडियो स्ट्रीम को संयोजित करना
3. **गुणवत्ता ऑडिट** - AI-संचालित विश्लेषण
4. **रिपोर्ट उत्पन्न करें** - व्यापक आउटपुट बनाना

**प्रोसेसिंग समय:**
10-मिनट का ऑडियो ≈ औसत लैपटॉप पर 5-7 मिनट

## गुणवत्ता स्कोरिंग को समझना

LocalMind केवल ट्रांसक्राइब नहीं करता—यह उन्नत AI तर्क का उपयोग करके आपकी बातचीत का मूल्यांकन करता है।

### डिफ़ॉल्ट पैरामीटर

**अनुपालन** (1.0x वजन)
- अभिवादन और परिचय
- सक्रिय श्रवण
- समस्या पहचान
- समाधान प्रदान किया गया
- उत्पाद ज्ञान
- संचार स्पष्टता
- सहानुभूति और संबंध
- कॉल नियंत्रण
- कॉल समापन
- स्क्रिप्ट अनुपालन

### स्कोर को अनुकूलित करना

0.1x से 3.0x तक पैरामीटर वजन समायोजित करें:

- **अधिक वजन** = समग्र स्कोर के लिए अधिक महत्वपूर्ण
- **कम वजन** = अंतिम रेटिंग पर कम प्रभाव

**उदाहरण:** बिक्री कॉल के लिए, "उत्पाद ज्ञान" को 2.5x तक बढ़ाएं

### स्कोरिंग कैसे काम करती है

LocalMind **चेन ऑफ़ थॉट (CoT) रीजनिंग** का उपयोग करता है:

1. पूर्ण ट्रांसक्रिप्ट संदर्भ का विश्लेषण करता है
2. प्रमुख क्षणों और पैटर्न की पहचान करता है
3. प्रत्येक पैरामीटर के विरुद्ध मूल्यांकन करता है
4. विस्तृत स्पष्टीकरण प्रदान करता है
5. भारित अंतिम स्कोर की गणना करता है

**परिणाम:** न केवल *क्या* कहा गया बल्कि *कितनी अच्छी तरह* संचार किया गया, यह समझें।

## सेटिंग्स

**सेटिंग्स** मेनू या `⌘,` (Command-Comma) के माध्यम से सेटिंग्स तक पहुंचें

### LLM प्रदाता

अपना AI प्रदाता चुनें:

**स्थानीय LLM (मुफ़्त, ऑफ़लाइन)**
- इंटरनेट की आवश्यकता नहीं
- पूर्ण गोपनीयता
- कोई API लागत नहीं
- अधिकांश उपयोगकर्ताओं के लिए अनुशंसित

**OpenAI API**
- API कुंजी की आवश्यकता है
- उपयोग के अनुसार भुगतान
- क्लाउड प्रोसेसिंग

**Anthropic API**
- API कुंजी की आवश्यकता है
- उन्नत तर्क
- क्लाउड प्रोसेसिंग

### ट्रांसक्रिप्शन सेटिंग्स

**मॉडल:** Large V3 (सर्वोत्तम गुणवत्ता)

**भाषा:** स्वतः-पहचान
स्वचालित रूप से बोली जाने वाली भाषा की पहचान करता है

**GPU त्वरण:**
3-5x तेज़ प्रोसेसिंग के लिए सक्षम करें (यदि उपलब्ध हो)

**उन्नत सेटिंग्स:**

- **चंक लंबाई:** 30 सेकंड (डिफ़ॉल्ट)
- **बैच आकार:** 16 (RAM के आधार पर समायोजित करें)

### आउटपुट सेटिंग्स

**आउटपुट डायरेक्टरी:**
चुनें कि परिणाम कहाँ सहेजें

**प्रोसेसिंग के बाद स्वतः-निर्यात:**
- ✓ स्वतः-निर्यात JSON
- ✓ स्वतः-निर्यात PDF

**PDF रिपोर्ट सेटिंग्स:**
- ✓ पूर्ण ट्रांसक्रिप्ट शामिल करें
- ✓ स्कोर विवरण शामिल करें

### दिखावट

**UI भाषा:**
English · Español · 日本語 · العربية · हिन्दी · Русский · Français · 中文

**थीम:**
गहरा · हल्का · सिस्टम

**पहुंच-योग्यता:**

## समस्या निवारण

### प्रोसेसिंग बहुत लंबी है

**यह प्रयास करें:**
- छोटा Whisper मॉडल उपयोग करें (Large के बजाय Medium)
- सेटिंग्स में GPU त्वरण सक्षम करें
- RAM खाली करने के लिए अन्य एप्लिकेशन बंद करें
- छोटे ऑडियो सेगमेंट प्रोसेस करें

### कम गुणवत्ता स्कोर

**याद रखें:**
- गुणवत्ता स्कोरिंग के लिए LLM डाउनलोड की आवश्यकता है
- पहली रन मॉडल डाउनलोड करती है (समय ले सकता है)
- सुनिश्चित करें "गुणवत्ता स्कोरिंग सक्षम करें" चेक है
- जांचें कि ऑडियो गुणवत्ता अच्छी है

### ऑडियो लोड नहीं हो रहा

**जांचें:**
- फ़ाइल प्रारूप समर्थित है (MP3, WAV, M4A, FLAC, OGG, WEBM)
- फ़ाइल आकार 2GB से कम है
- फ़ाइल दूषित नहीं है
- आपके पास फ़ाइल के लिए पढ़ने की अनुमति है
