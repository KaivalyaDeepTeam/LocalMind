## परिचय

LocalMind एक डेस्कटॉप एप्लिकेशन है जो दो अलग-अलग AI कार्य करता है:

| कार्य | प्रौद्योगिकी | उद्देश्य |
|------|------------|---------|
| **प्रतिलेखन** | OpenAI Whisper | वाणी को टेक्स्ट में बदलना |
| **गुणवत्ता विश्लेषण** | स्थानीय/क्लाउड LLM | वार्तालाप का स्कोर और विश्लेषण |

ये **अलग-अलग सिस्टम** हैं जो एक साथ काम करते हैं लेकिन स्वतंत्र रूप से भी उपयोग किए जा सकते हैं।

# खंड A: प्रतिलेखन (Speech-to-Text)

यह खंड OpenAI के Whisper तकनीक का उपयोग करके **ऑडियो को टेक्स्ट में बदलने** के बारे में है।

---

## प्रतिलेखन क्या है?

प्रतिलेखन ऑडियो फ़ाइलों में बोले गए शब्दों को लिखित टेक्स्ट में बदलता है। LocalMind **OpenAI Whisper** का उपयोग करता है।

### यह कैसे काम करता है

```
Audio File → Whisper AI → Written Transcript
   (MP3)       (Local)        (Text)
```

### मुख्य विशेषताएं

- **50+ भाषाएं** समर्थित
- **स्वचालित भाषा पहचान**
- **वक्ता पहचान** (diarization)
- **प्रत्येक खंड के लिए टाइमस्टैम्प**
- **मॉडल डाउनलोड के बाद पूर्णतः ऑफलाइन काम करता है**

### समर्थित ऑडियो प्रारूप

| प्रारूप | एक्सटेंशन | विवरण |
|--------|-----------|-------|
| MP3 | .mp3 | सबसे आम प्रारूप |
| WAV | .wav | असंपीड़ित, उच्च गुणवत्ता |
| M4A | .m4a | Apple/iTunes प्रारूप |
| FLAC | .flac | लॉसलेस कम्प्रेशन |
| OGG | .ogg | ओपन सोर्स प्रारूप |
| WebM | .webm | वेब ऑडियो प्रारूप |

**अधिकतम फ़ाइल आकार:** 2 GB प्रति फ़ाइल

# खंड B: LLM गुणवत्ता विश्लेषण

यह खंड Large Language Models का उपयोग करके **AI-संचालित वार्तालाप विश्लेषण** के बारे में है।

---

## LLM विश्लेषण क्या है?

LLM विश्लेषण आपकी ट्रांसक्रिप्ट पढ़ता है और वार्तालाप की गुणवत्ता का मूल्यांकन करता है। यह प्रदान करता है:

- **समग्र स्कोर** (0-100%)
- **पैरामीटर स्कोर** (अनुकूलन योग्य मानदंड)
- **शक्तियां** जो वार्तालाप में पहचानी गईं
- **सुधार के क्षेत्र**
- **प्रत्येक पैरामीटर के लिए विस्तृत फीडबैक**

### प्रतिलेखन से मुख्य अंतर

| पहलू | प्रतिलेखन | LLM विश्लेषण |
|-----|----------|-------------|
| **इनपुट** | ऑडियो फ़ाइल | टेक्स्ट ट्रांसक्रिप्ट |
| **आउटपुट** | लिखित टेक्स्ट | स्कोर और फीडबैक |
| **प्रौद्योगिकी** | Whisper | LLM (Phi/Qwen/GPT) |
| **उद्देश्य** | वाणी को बदलना | गुणवत्ता का मूल्यांकन |
| **आवश्यक?** | हां | वैकल्पिक |
