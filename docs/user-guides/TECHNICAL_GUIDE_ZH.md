## 快速入门

### 您需要什么

- **macOS** 10.15或更高版本
- **4GB RAM** 最低（推荐8GB）
- **音频文件** MP3、WAV、M4A、FLAC、OGG或WEBM格式

### 首次启动

1. 下载LocalMind
2. 移动到应用程序文件夹
3. 双击打开
4. 如提示则授予权限

就是这样。无需账户。无需订阅。无需互联网。

## 您的第一次转录

### 步骤1：添加您的音频

将音频文件拖放到窗口中。

**支持的格式:**
MP3 · WAV · M4A · FLAC · OGG · WEBM

**文件大小:**
每个文件最大2GB

### 步骤2：配置处理

选择您的偏好:

**处理模式:**
- **离线** - 在您的设备上本地处理
- **在线** - 使用云AI（需要API密钥）

**语言:**
自动检测或从50多种语言中选择

**模型:**
Large V3（最佳质量） - 推荐首次使用

### 步骤3：处理

点击**处理**并观察流程:

1. **转录** - 将语音转换为文本
2. **合并频道** - 合并音频流
3. **质量审核** - AI驱动的分析
4. **生成报告** - 创建综合输出

**处理时间:**
10分钟音频 ≈ 在普通笔记本电脑上5-7分钟

## 理解质量评分

LocalMind不仅仅是转录—它使用先进的AI推理评估您的对话。

### 默认参数

**合规性**（1.0x权重）
- 问候和介绍
- 积极倾听
- 问题识别
- 提供的解决方案
- 产品知识
- 沟通清晰度
- 同理心和融洽关系
- 通话控制
- 通话结束
- 脚本合规性

### 自定义分数

将参数权重从0.1x调整到3.0x:

- **更高权重** = 对总分更重要
- **更低权重** = 对最终评级影响较小

### 评分如何工作

LocalMind使用**思维链（CoT）推理**:

1. 分析完整的转录上下文
2. 识别关键时刻和模式
3. 针对每个参数进行评估
4. 提供详细解释
5. 计算加权最终分数

## 故障排除

### 处理时间过长

**尝试此操作:**
- 使用更小的Whisper模型（Medium而不是Large）
- 在设置中启用GPU加速
- 关闭其他应用程序以释放RAM

### 质量分数低

**记住:**
- 质量评分需要下载LLM
- 首次运行下载模型（可能需要时间）

## 隐私和安全

### LocalMind收集什么

**什么都不收集。**

- 无遥测
- 无分析
- 无崩溃报告
- 无使用统计

在离线模式下，您的音频永远不会离开您的设备。

### 数据存储

所有数据本地存储:
- **转录:** 您选择的输出目录
- **模型:** `~/.cache/localmind/`
- **设置:** `~/Library/Application Support/localmind/`
