## البدء السريع

### ما تحتاجه

- **macOS** 10.15 أو أحدث
- **4GB RAM** كحد أدنى (8GB موصى به)
- **ملف صوتي** بتنسيق MP3 أو WAV أو M4A أو FLAC أو OGG أو WEBM

### الإطلاق الأول

1. تحميل LocalMind
2. نقل إلى مجلد التطبيقات
3. النقر المزدوج للفتح
4. منح الأذونات إذا طلب منك

هذا كل شيء. بلا حساب. بلا اشتراك. بلا إنترنت مطلوب.

## أول نسخ لك

### الخطوة 1: أضف الصوت الخاص بك

اسحب وأفلت ملف الصوت الخاص بك في النافذة.

**التنسيقات المدعومة:**
MP3 · WAV · M4A · FLAC · OGG · WEBM

**حجم الملف:**
حتى 2GB لكل ملف

### الخطوة 2: تكوين المعالجة

اختر تفضيلاتك:

**وضع المعالجة:**
- **دون اتصال** - معالجة محلياً على جهازك
- **متصل** - يستخدم الذكاء الاصطناعي السحابي (يتطلب مفاتيح API)

**اللغة:**
الكشف التلقائي أو الاختيار من أكثر من 50 لغة

**النموذج:**
Large V3 (أفضل جودة) - موصى به للاستخدام الأول

### الخطوة 3: المعالجة

انقر على **معالجة** ولاحظ خط الأنابيب:

1. **النسخ** - تحويل الكلام إلى نص
2. **دمج القنوات** - دمج تدفقات الصوت
3. **تدقيق الجودة** - تحليل مدعوم بالذكاء الاصطناعي
4. **إنشاء التقرير** - إنشاء ال

خرج الشامل

**وقت المعالجة:**
صوت 10 دقائق ≈ 5-7 دقائق على حاسوب محمول متوسط

## فهم تقييم الجودة

LocalMind لا ينسخ فقط—إنه يقيّم محادثاتك باستخدام التفكير المتقدم بالذكاء الاصطناعي.

### المعاملات الافتراضية

**الامتثال** (وزن 1.0x)
- التحية والمقدمة
- الاستماع النشط
- تحديد المشكلة
- الحل المقدم
- معرفة المنتج
- وضوح التواصل
- التعاطف والعلاقة
- التحكم في المكالمة
- إغلاق المكالمة
- امتثال السكريبت

### تخصيص النتائج

اضبط أوزان المعاملات من 0.1x إلى 3.0x:

- **وزن أعلى** = أكثر أهمية للنتيجة الإجمالية
- **وزن أقل** = تأثير أقل على التصنيف النهائي

### كيف يعمل التقييم

يستخدم LocalMind **تفكير سلسلة الأفكار (CoT)**:

1. تحليل السياق الكامل للنسخ
2. تحديد اللحظات والأنماط الرئيسية
3. التقييم مقابل كل معامل
4. تقديم تفسيرات مفصلة
5. حساب النتيجة النهائية الموزونة

## اختيار النموذج المناسب

### نماذج النسخ

#### Qwen 2.5 (7B) - الأفضل للتدقيق (موصى به)

- **الحجم:** 4GB
- **السرعة:** سريع
- **الجودة:** مخرجات JSON ممتازة
- **الأفضل لـ:** تحليل الجودة، الاستخدام المهني

#### Whisper Large V3
- دقة قصوى (97-99%)
- مثالي للنسخ الحرج

## الإعدادات

الوصول إلى الإعدادات عبر قائمة **الإعدادات** أو `⌘,` (Command-فاصلة)

### مزود LLM

اختر مزود الذكاء الاصطناعي الخاص بك:

**LLM المحلي (مجاني، دون اتصال)**
- لا يتطلب إنترنت
- خصوصية كاملة
- بلا تكاليف API
- موصى به لمعظم المستخدمين

**OpenAI API / Anthropic API**
- يتطلب مفتاح API
- معالجة سحابية

### إعدادات النسخ

**النموذج:** Large V3 (أفضل جودة)
**اللغة:** الكشف التلقائي
**تسريع GPU:** تمكين للمعالجة أسرع 3-5 مرات

### إعدادات الإخراج

**دليل الإخراج:** اختر أين تحفظ النتائج

**التصدير التلقائي بعد المعالجة:**
- ✓ تصدير JSON تلقائياً
- ✓ تصدير PDF تلقائياً

### المظهر

**لغة الواجهة:**
English · Español · 日本語 · العربية · हिन्दी · Русский · Français · 中文

**السمة:** داكن · فاتح · النظام

## استكشاف الأخطاء وإصلاحها

### المعالجة تستغرق وقتاً طويلاً

**جرب هذا:**
- استخدم نموذج Whisper أصغر (Medium بدلاً من Large)
- تمكين تسريع GPU في الإعدادات
- إغلاق تطبيقات أخرى لتحرير RAM

### درجات جودة منخفضة

**تذكر:**
- تقييم الجودة يتطلب تنزيل LLM
- التشغيل الأول يقوم بتنزيل النماذج (قد يستغرق وقتاً)

## الخصوصية والأمان

### ما الذي يجمعه LocalMind

**لا شيء.**

- بلا قياس عن بعد
- بلا تحليلات
- بلا تقارير أعطال
- بلا إحصائيات استخدام

صوتك لا يغادر جهازك أبداً في الوضع دون اتصال.

### تخزين البيانات

جميع البيانات مخزنة محلياً:
- **النسخ:** دليل الإخراج المختار
- **النماذج:** `~/.cache/localmind/`
- **الإعدادات:** `~/Library/Application Support/localmind/`
