## مقدمة

LocalMind هو تطبيق سطح مكتب يقوم بمهمتين منفصلتين للذكاء الاصطناعي:

| المهمة | التقنية | الغرض |
|--------|---------|-------|
| **النسخ** | OpenAI Whisper | تحويل الكلام إلى نص |
| **تحليل الجودة** | LLM محلي/سحابي | تقييم وتحليل المحادثات |

هذه **أنظمة منفصلة** تعمل معاً ولكن يمكن استخدامها بشكل مستقل.

# القسم أ: النسخ (تحويل الكلام إلى نص)

يغطي هذا القسم **تحويل الصوت إلى نص** باستخدام تقنية Whisper من OpenAI.

---

## ما هو النسخ؟

النسخ يحوّل الكلمات المنطوقة في الملفات الصوتية إلى نص مكتوب. يستخدم LocalMind **OpenAI Whisper**.

### كيف يعمل

```
Audio File → Whisper AI → Written Transcript
   (MP3)       (Local)        (Text)
```

### الميزات الرئيسية

- **أكثر من 50 لغة** مدعومة
- **كشف اللغة التلقائي**
- **تحديد المتحدثين** (diarization)
- **طوابع زمنية** لكل مقطع
- **يعمل دون اتصال بالكامل** بعد تنزيل النموذج

### صيغ الصوت المدعومة

| الصيغة | الامتداد | الوصف |
|--------|----------|-------|
| MP3 | .mp3 | الصيغة الأكثر شيوعاً |
| WAV | .wav | غير مضغوط، جودة عالية |
| M4A | .m4a | صيغة Apple/iTunes |
| FLAC | .flac | ضغط بدون فقدان |
| OGG | .ogg | صيغة مفتوحة المصدر |
| WebM | .webm | صيغة صوت الويب |

**الحد الأقصى لحجم الملف:** 2 جيجابايت لكل ملف

# القسم ب: تحليل الجودة بـ LLM

يغطي هذا القسم **تحليل المحادثات بالذكاء الاصطناعي** باستخدام نماذج اللغة الكبيرة.

---

## ما هو تحليل LLM؟

تحليل LLM يقرأ النص المنسوخ ويقيّم جودة المحادثة. يوفر:

- **درجة إجمالية** (0-100%)
- **درجات المعايير** (معايير قابلة للتخصيص)
- **نقاط القوة** المحددة في المحادثة
- **مجالات التحسين**
- **ملاحظات تفصيلية** لكل معيار

### الفرق الرئيسي عن النسخ

| الجانب | النسخ | تحليل LLM |
|--------|-------|-----------|
| **المدخل** | ملف صوتي | نص منسوخ |
| **المخرج** | نص مكتوب | درجات وملاحظات |
| **التقنية** | Whisper | LLM (Phi/Qwen/GPT) |
| **الغرض** | تحويل الكلام | تقييم الجودة |
| **مطلوب؟** | نعم | اختياري |

---

## خيارات مزود LLM

### 1. LLM محلي (موصى به)

| المزايا | العيوب |
|---------|--------|
| مجاني 100% | أبطأ من السحابة |
| خصوصية كاملة | يتطلب 8+ جيجابايت RAM |
| لا يحتاج إنترنت | تنزيل نموذج كبير |

### 2. OpenAI API

| المزايا | العيوب |
|---------|--------|
| سريع جداً | يكلف مالاً |
| جودة عالية | يتطلب إنترنت |

### 3. Anthropic API

| المزايا | العيوب |
|---------|--------|
| استدلال ممتاز | يكلف مالاً |
| رائع للتحليل | يتطلب إنترنت |
