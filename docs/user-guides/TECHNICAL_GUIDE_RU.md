## Введение

LocalMind — настольное приложение, выполняющее две отдельные AI-задачи:

| Задача | Технология | Назначение |
|--------|------------|------------|
| **Транскрипция** | OpenAI Whisper | Преобразование речи в текст |
| **Анализ качества** | Локальный/облачный LLM | Оценка и анализ разговоров |

Это **отдельные системы**, работающие вместе, но использующиеся независимо.

## Установка и первый запуск

### Шаг 1: Скачивание

Загрузите `LocalMind-1.2.0-macOS.dmg` с:
[github.com/KaivalyaDeepTeam/LocalMind/releases](https://github.com/KaivalyaDeepTeam/LocalMind/releases)

1. Откройте загруженный DMG-файл

**Важно:** macOS может заблокировать приложение, так как оно не из App Store.

2. Выберите «Открыть» в меню

# Раздел A: Транскрипция (Речь в текст)

Этот раздел описывает **преобразование аудио в текст** с использованием технологии Whisper от OpenAI.

---

## Что такое транскрипция?

Транскрипция преобразует устную речь в аудиофайлах в письменный текст. LocalMind использует **OpenAI Whisper**.

### Как это работает

```
Audio File → Whisper AI → Written Transcript
   (MP3)       (Local)        (Text)
```

### Ключевые возможности

- **50+ языков** поддерживается
- **Автоматическое определение языка**
- **Идентификация говорящих** (диаризация)
- **Временные метки** для каждого сегмента
- **Полностью офлайн** после загрузки модели

### Поддерживаемые форматы аудио

| Формат | Расширение | Описание |
|--------|------------|----------|
| MP3 | .mp3 | Самый распространённый формат |
| WAV | .wav | Несжатый, высокое качество |
| M4A | .m4a | Формат Apple/iTunes |
| FLAC | .flac | Сжатие без потерь |
| OGG | .ogg | Открытый формат |
| WebM | .webm | Веб-аудио формат |

**Максимальный размер файла:** 2 ГБ на файл

# Раздел B: LLM-анализ качества

Этот раздел описывает **AI-анализ разговоров** с использованием больших языковых моделей.

---

## Что такое LLM-анализ?

LLM-анализ читает вашу транскрипцию и оценивает качество разговора. Он предоставляет:

- **Общую оценку** (0-100%)
- **Оценки по параметрам** (настраиваемые критерии)
- **Сильные стороны**, выявленные в разговоре
- **Области для улучшения**
- **Подробную обратную связь** для каждого параметра

### Ключевое отличие от транскрипции

| Аспект | Транскрипция | LLM-анализ |
|--------|--------------|------------|
| **Вход** | Аудиофайл | Текстовая транскрипция |
| **Выход** | Письменный текст | Оценки и обратная связь |
| **Технология** | Whisper | LLM (Phi/Qwen/GPT) |
| **Назначение** | Преобразование речи | Оценка качества |
| **Обязательно?** | Да | Опционально |

---

## Варианты LLM-провайдеров

### 1. Локальный LLM (рекомендуется)

| Преимущества | Недостатки |
|--------------|------------|
| 100% бесплатно | Медленнее облака |
| Полная конфиденциальность | Требуется 8+ ГБ RAM |
| Не нужен интернет | Большая загрузка модели |

### 2. OpenAI API

| Преимущества | Недостатки |
|--------------|------------|
| Очень быстро | Стоит денег |
| Высокое качество | Требуется интернет |

### 3. Anthropic API

| Преимущества | Недостатки |
|--------------|------------|
| Отличное рассуждение | Стоит денег |
| Идеально для анализа | Требуется интернет |

| **Local LLM** | Остаётся на устройстве | Остаётся на устройстве |
