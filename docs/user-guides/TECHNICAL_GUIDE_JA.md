## はじめに

LocalMindは2つの異なるAIタスクを実行するデスクトップアプリケーションです：

| タスク | テクノロジー | 目的 |
|--------|-------------|------|
| **文字起こし** | OpenAI Whisper | 音声をテキストに変換 |
| **品質分析** | ローカル/クラウドLLM | 会話のスコアリングと分析 |

これらは**別々のシステム**であり、連携して動作しますが、独立して使用することもできます。

## インストールと初回起動

### ステップ1：ダウンロード

以下から `LocalMind-1.2.0-macOS.dmg` をダウンロード：
[github.com/KaivalyaDeepTeam/LocalMind/releases](https://github.com/KaivalyaDeepTeam/LocalMind/releases)

### ステップ2：インストール

1. ダウンロードしたDMGファイルを開く
2. LocalMindをApplicationsフォルダにドラッグ
3. DMGを取り出す

### ステップ3：初回起動

**重要：** macOSはApp Store外のアプリをブロックする場合があります。

**LocalMindを開くには：**

1. LocalMind.appを右クリック
2. メニューから「開く」を選択
3. セキュリティダイアログで「開く」をクリック

# セクションA：文字起こし（音声からテキストへ）

このセクションでは、OpenAIのWhisper技術を使用した**音声からテキストへの変換**について説明します。

---

## 文字起こしとは？

文字起こしは、オーディオファイル内の話し言葉を書き言葉に変換します。LocalMindは**OpenAI Whisper**を使用しています。

### 仕組み

```
Audio File → Whisper AI → Written Transcript
   (MP3)       (Local)        (Text)
```

### 主な機能

- **50以上の言語**をサポート
- **自動言語検出**
- **話者識別**（ダイアライゼーション）
- 各セグメントの**タイムスタンプ**
- モデルダウンロード後は**完全オフライン動作**

### サポートされるオーディオ形式

| 形式 | 拡張子 | 説明 |
|------|--------|------|
| MP3 | .mp3 | 最も一般的な形式 |
| WAV | .wav | 非圧縮、高品質 |
| M4A | .m4a | Apple/iTunes形式 |
| FLAC | .flac | ロスレス圧縮 |
| OGG | .ogg | オープンソース形式 |
| WebM | .webm | Webオーディオ形式 |

**最大ファイルサイズ：** ファイルあたり2 GB

# セクションB：LLM品質分析

このセクションでは、大規模言語モデルを使用した**AI駆動の会話分析**について説明します。

---

## LLM分析とは？

LLM分析は文字起こしを読み取り、会話の品質を評価します。以下を提供します：

- **総合スコア**（0-100%）
- **パラメータスコア**（カスタマイズ可能な基準）
- 会話で特定された**強み**
- **改善点**
- 各パラメータの**詳細フィードバック**

### 文字起こしとの主な違い

| 側面 | 文字起こし | LLM分析 |
|------|-----------|---------|
| **入力** | オーディオファイル | テキスト文字起こし |
| **出力** | 書き起こしテキスト | スコアとフィードバック |
| **技術** | Whisper | LLM (Phi/Qwen/GPT) |
| **目的** | 音声の変換 | 品質の評価 |
| **必須？** | はい | オプション |

---
