## クイックスタート

### 必要なもの

- **macOS** 10.15以降
- **4GB RAM** 最小（8GB推奨）
- **オーディオファイル** MP3、WAV、M4A、FLAC、OGG、またはWEBM形式

### 初回起動

1. LocalMindをダウンロード
2. Applicationsフォルダに移動
3. ダブルクリックして開く
4. プロンプトが表示されたら権限を付与

それだけです。アカウント不要。サブスクリプション不要。インターネット不要。

## 最初の文字起こし

### ステップ1：オーディオを追加

オーディオファイルをウィンドウにドラッグアンドドロップします。

**サポートされている形式:**
MP3 · WAV · M4A · FLAC · OGG · WEBM

**ファイルサイズ:**
ファイルあたり最大2GB

### ステップ2：処理の設定

設定を選択:

**処理モード:**
- **オフライン** - デバイス上でローカル処理
- **オンライン** - クラウドAIを使用（APIキーが必要）

**言語:**
自動検出または50以上の言語から選択

**モデル:**
Large V3（最高品質） - 初回使用時に推奨

### ステップ3：処理

**処理**をクリックしてパイプラインを観察:

1. **文字起こし** - 音声をテキストに変換
2. **チャンネルの結合** - オーディオストリームの結合
3. **品質監査** - AI搭載の分析
4. **レポート生成** - 包括的な出力の作成

**処理時間:**
10分のオーディオ ≈ 平均的なノートパソコンで5-7分

## 品質スコアリングの理解

LocalMindは単に文字起こしするだけでなく、高度なAI推論を使用して会話を評価します。

### デフォルトパラメータ

**コンプライアンス**（1.0x重み）
- 挨拶と紹介
- アクティブリスニング
- 問題の特定
- ソリューションの提供
- 製品知識
- コミュニケーションの明確さ
- 共感とラポール
- 通話コントロール
- 通話クロージング
- スクリプトコンプライアンス

### スコアのカスタマイズ

パラメータの重みを0.1xから3.0xに調整:

- **重み大** = 総合スコアにより重要
- **重み小** = 最終評価への影響が少ない

### スコアリングの仕組み

LocalMindは**Chain-of-Thought（CoT）推論**を使用:

1. 完全な文字起こしコンテキストを分析
2. 主要な瞬間とパターンを特定
3. 各パラメータに対して評価
4. 詳細な説明を提供
5. 加重最終スコアを計算

AIプロバイダーを選択:

**ローカルLLM（無料、オフライン）**
- インターネット不要

- APIキーが必要
- クラウド処理

**モデル:** Large V3（最高品質）

## トラブルシューティング

### 処理に時間がかかりすぎる

**これを試してください:**
- より小さいWhisperモデルを使用（LargeではなくMedium）
- 設定でGPU加速を有効化
- RAMを解放するために他のアプリケーションを閉じる

### 品質スコアが低い

**覚えておいてください:**
- 品質スコアリングにはLLMのダウンロードが必要
- 初回実行時にモデルをダウンロード（時間がかかる場合があります）

## プライバシーとセキュリティ

### LocalMindが収集するもの

**何もありません。**

- テレメトリーなし
- 分析なし
- クラッシュレポートなし
- 使用統計なし

オフラインモードでは、オーディオがデバイスから出ることはありません。

### データストレージ

すべてのデータはローカルに保存:
- **文字起こし:** 選択した出力ディレクトリ
- **モデル:** `~/.cache/localmind/`
- **設定:** `~/Library/Application Support/localmind/`
